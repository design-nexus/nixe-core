# Core

Shared Rust workspace: nixe-core (identity, paths, preferences, control),
nixe-accounts (GOA accounts, EDS discovery, mail settings and, behind the
`credentials` feature, in-process GOA tokens), nixe-eds (EDS calendars and task
lists), nixe-when (natural-language dates) and nixe-sync (WebDAV journal).

`crates/eds/*-sys` are FFI crates generated by gir from the EDS 3.62 GIR files
(`tools/gen-eds.sh`; the generated code is committed). `tools/test-eds.sh` runs the
nixe-eds tests against a real EDS on a private session bus.

Check: `cargo check --locked --workspace`. Headless foundation: `cargo check --locked -p nixe-core --no-default-features`.

Architecture and public API boundaries: [AGENTS.md](AGENTS.md). Mail, Calendar and Reminders foundation: [docs/pim/ARCHITECTURE.md](docs/pim/ARCHITECTURE.md).
